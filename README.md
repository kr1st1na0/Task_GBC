```
|   |-- job.py
|-- services/           # внешнее

|-- storage/            # хранилище

|-- tasks/
|   |-- broker.py

|-- config.py           # настройки
|-- main.py
```

## Запуск:

- первый запуск
```bash
docker compose up --build
```

- запуск
```bash
docker compose up 
```

- посмотреть redis:
```bash
docker exec -it redis_storage redis-cli
```
- очистить redis:
```bash
docker exec -it redis_storage redis-cli FLUSHALL
```
