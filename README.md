## Запуск:

- первый запуск
```bash
docker compose up --build
```

- запуск
```bash
docker compose up 
```

- посмотреть redis:
```bash
docker exec -it redis_storage redis-cli
```
- очистить redis:
```bash
docker exec -it redis_storage redis-cli FLUSHALL
```

- **Обработка дубликатов**: 
1. Единый запуск: если встречаем заказ с таким же ```order_id```, какой уже видели (проверяем через множество ```local_seen_ids``` - только для текущего запуска), то кладем в ```errors``` c причиной ```"duplicate order"```

тут все норм:

файл с заказами ```[1, 2, 1, 1, 3]```
| order_id | local_seen_ids | all_seen_ids | результат |
|-|-|-|-|
| 1 |  {} -> {1} | {} -> {1} | обработали |
| 2 | {1} -> {1, 2} | {1} -> {1, 2} | обработали |
| 1 | {1, 2} -> {1, 2} | {1, 2} -> {1, 2} | дубликат |
| 1 | {1, 2} -> {1, 2} | {1, 2} -> {1, 2} | дубликат |
| 3 | {1, 2} -> {1, 2, 3} | {1, 2} -> {1, 2, 3} | обработали |
Итог: 
```processed_orders = [1, 2, 3]```
```errors = [{1, "duplicate order"}, {1, "duplicate order"}]```
```total = 5```
```processed = 3```
```failed = 2```

2. Retry запуск: для этого храним в Redis ```all_seen_ids``` - хранятся все ```order_id```, которые когда-либо видели (предыдущие запуски + текущий запуск).
